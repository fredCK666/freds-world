# CardFlow 點數作業管理台

公開展示網址：https://fredck666.github.io/freds-world/cardflow-demo/

此資料夾是本專案後續修改與部署的固定來源；更新提交至 `fredCK666/freds-world` 的 `main` 分支，由既有 GitHub Pages 發布。請同步更新 HTML 中的靜態資源版本參數以避免舊快取。不要覆蓋根目錄的個人作品集。

## 檔案
- `index.html`、`login.js`：展示密碼入口。
- `app.html`、`app.js`、`style.css`：管理台與操作模擬。
- `gate.js`：分頁登入狀態及直接開啟管理台時的導回。

## 展示範圍
點卡 Excel／CSV 匯入、QR 圖片任務清單、模擬執行／暫停／停止、模擬批次鎖定、交易查詢、CSV 匯出與複製回覆。所有交易均為模擬，未串接 MyCard、QR 解碼或真實付款。

此密碼入口只提供前端展示流程；原始碼為公開靜態資源，並非安全驗證或存取控制。不得放入真實密鑰、正式卡密或客戶交易資料。登入狀態使用分頁 sessionStorage；重新整理會重置示範交易資料。

## v0.2 新增展示
- 點卡批次儲值到會員帳戶，逐張入帳、暫停續跑、已使用卡片不重複入帳。
- 點卡可用／已儲值／批次鎖定狀態與遮罩狀態 CSV 匯出。
- QR 任務可編輯客戶、遊戲、示範點數與優先順序；一鍵增加 20 筆、清除已完成、複製批次摘要。
- 下一筆交易可選擇成功、QR 過期、手機驗證、結果待確認、風控鎖定。
- 異常停止後的手動恢復流程；結果不明時必須先選擇核對結果，不直接重送。
- 交易紀錄分為會員儲值／會員扣點；自訂回覆模板、操作日誌與匯出。

## 與客戶對話的範圍對照
已明確提出：Windows 電腦上的網頁介面、暗色系、Excel 點卡匯入、點卡先儲值到自己的會員帳戶、客戶 QR 截圖批次排隊、結果流水帳、格式化回覆、異常紅色警示與鎖定批次。上述已用模擬資料呈現操作流程。

仍待確認或正式串接：QR 真實解碼、會員驗證與官方付款、是否完全不需要手機或模擬器、官方風控狀態辨識、遊戲支援範圍、正式併發量。「卡密逐單付款」與原先會員儲值流程不同，未視為已確認需求。參考圖片的員工管理、代理、帳號註冊等頁籤未納入已確認範圍。任何代理設定都不能保證繞過驗證或風控。

本版未實作正式帳號認證、持久化交易資料或金流；Excel 鎖定是系統批次的模擬狀態，不修改或加密原始檔。


## v0.3 三語介面
登入頁與管理台右上角提供繁體中文、簡體中文、English 切換。`localStorage` 僅記住介面語言，登入前後沿用同一設定。切換語言不會重設任務、餘額或作業狀態。動態提示、對話框、交易狀態、回覆與 CSV 匯出支援三語；手動編輯的回覆保留原文。

- `i18n.js`：語言狀態、動態介面更新及回覆／匯出轉換。
- `translations.js`：瀏覽器使用的英語詞典與簡體轉換資料，無外部翻譯 API。
- `en.tsv`：英文翻譯來源。
- `i18n.css`：語言選單與英文長文字版面。

回覆模板欄位接受繁體、簡體與英文（Customer/Game/Credits/Order/Time，大小寫皆可）。點卡匯入欄位支援「卡號/卡号/card_no」與「面額/面额/amount」。
